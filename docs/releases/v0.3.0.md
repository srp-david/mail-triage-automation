# v0.3.0 패치노트

<!-- 게시 전 초안. 현재 로컬 설치 파일만 생성했으며 GitHub Release와 업데이트 catalog는 갱신하지 않았다. -->
기준 범위: `v0.3.0-candidate.10`과 이번 `v0.3.0` 배포 예정 소스를 비교했습니다.

v0.3.0은 설치 후 웹 화면에서 개인 연결을 설정하고, Codex·Claude에 등록된 MCP를 찾아 연결 준비를 할 수 있도록 개선한 버전입니다.

## 웹에서 연결 환경 설정

- `설정 → 개인 연결 → 연결 환경`에서 Mail MCP·DB MCP 주소와 Codex·Claude Code 실행 경로를 입력할 수 있습니다. Node로 실행하는 도구는 실행 인수도 입력할 수 있습니다.
- ERP 코드와 참고 자료 폴더를 추가·수정·제거할 수 있습니다. 개인 설정이나 자격 증명 폴더는 읽기 자료로 지정할 수 없습니다.
- 저장하면 앱이 설정 파일을 갱신하고 실행 연결을 반영합니다. 기존 서버 주소·로그인 설정·포트와 기타 설정은 보존합니다.
- 다른 화면에서 설정을 바꾼 경우에는 다시 불러오도록 안내합니다. 분석·동기화 작업 중에는 완료 후 저장할 수 있고, 대기 중인 실행은 저장 시 중지됩니다. 저장 후 사용할 출처·장치를 확인하고 실행을 다시 켜세요.

## MCP 자동 찾기와 연결 확인

- Codex·Claude의 기존 HTTP MCP 설정과 이 PC의 기본 Mail/DB MCP 주소를 확인합니다. 연결 가능한 서버의 도구 목록을 보고 종류를 구분합니다.
- 연결을 하나 찾으면 빈 입력란에 채우고, 여러 개면 선택할 수 있습니다. 이미 입력한 값은 유지하며 저장 버튼을 눌러야 적용됩니다.
- MCP 연결 확인과 AI 도구 실행·호환성 확인 버튼을 추가했습니다. 자동 찾기와 MCP 연결 확인은 메일 원문이나 ERP 업무 데이터를 조회하지 않습니다.
- 인증 헤더·OAuth·stdio 방식의 MCP는 자동 가져오기를 지원하지 않습니다. Codex·Claude의 설치와 제공자 로그인은 각 도구에서 진행해야 합니다.

## DB 구조 조회 연결

- DB MCP에서 데이터베이스 목록, 스키마 목록, 테이블 목록, 테이블 구조를 읽는 도구를 분석 근거에 연결했습니다.
- 자유 SQL이나 쓰기 도구는 제공하지 않습니다. 실제 업무 데이터 조회와 지정 메일의 분석 결과는 별도 확인이 필요합니다.

## 설치 및 업데이트

- Windows x64 설치 파일은 `0.3.0-setup.exe`입니다. 실행 중인 앱을 종료한 뒤 기존 설치 위치에 설치하세요.
- 기존 메일 주소를 바꾼 경우에는 메일 출처를 새로 등록하거나, 같은 저장소임을 확인하는 기존 원본 재연결 절차를 진행하세요.
- 이전 candidate 버전은 보존하며 이번 버전부터 릴리스 제목은 숫자 버전으로 표시합니다.

## 확인된 사항과 알려진 제한

- 정적 검사·빌드, 관련 단위/UI 테스트 21개, 합성 브라우저의 자동 입력·수정·저장·새로고침·모바일 표시를 확인했습니다.
- 패키징한 앱의 실행·일시 중지·종료와 설정 보존을 확인했습니다. 개인 계정 로그인과 실제 메일 분석의 완료를 뜻하지 않습니다.
- 별도 테스트 설치 위치에서 candidate.10→v0.3.0 설치와 기존 서버 주소·포트·메일 주소·작업 파일 보존을 확인했습니다.
- 설치 EXE에는 Windows Authenticode 서명이 없으므로 SmartScreen 경고가 표시될 수 있습니다.
