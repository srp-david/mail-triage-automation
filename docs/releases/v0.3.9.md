# v0.3.9 패치노트

<!-- 로컬 설치본. GitHub Release와 업데이트 catalog 미게시. -->
기준 범위: 로컬 v0.3.8 대비 변경입니다.

## 팝업 정렬과 여백 개선

- 임시 비밀번호 창의 계정 정보·입력칸·안내문을 정렬하고 작은 화면에서도 전체 비밀번호가 보이도록 했습니다.
- 분석 이력의 제목과 날짜를 분리하고 팝업 제목·도구·본문의 여백을 정리했습니다.
- 공유 분석·재분석 버튼 간격을 늘리고 좁은 화면에서는 줄바꿈하도록 했습니다.
- 보고서 편집·대화·AI 질문 입력칸을 세로로 정렬했습니다.
- 공유 분석의 닫기 버튼과 첨부 미리보기 버튼 배치를 정리했습니다.

## 설치 및 확인

- 트레이에서 **앱 종료** 후 `0.3.9-setup.exe`를 기존 위치에 설치하고 바로가기로 실행하세요.
- v0.3.8의 동기화·분석 자동 실행과 알림 자동 닫힘도 포함합니다.
- 합성 계정·보고서로 PC/390px 모바일 배치, 버튼 간격, 가로 넘침, 닫기와 계정 화면 동작을 확인했습니다. 실제 계정·비밀번호·메일은 변경하지 않았습니다.
- 별도 폴더에서 실제 설치 파일로 0.3.8→0.3.9 업그레이드해 설정·작업 파일 보존과 새 UI 제공을 확인했습니다.
