# v0.3.1 패치노트

<!-- 로컬 설치본 초안. GitHub Release와 업데이트 catalog에는 아직 게시하지 않았다. -->
기준 범위: 로컬 v0.3.0 설치본 이후의 실행·종료 기능 개선입니다. v0.3.0의 웹 연결 환경 설정도 포함합니다.

v0.3.1은 바탕화면에서 앱을 실행하고 Windows 트레이에서 작업과 종료를 관리할 수 있도록 개선한 버전입니다.

## 바탕화면에서 실행

- 설치하면 **메일 분석실** 바로가기를 만듭니다.
- 실행 중인 앱이 있으면 같은 앱의 웹 화면을 다시 엽니다.
- 바로가기와 트레이에 봉투 아이콘을 적용했습니다.

## 트레이에서 앱 관리

- **화면 열기**, **환경설정**, **작업 중지**, **작업 재개**, **앱 종료** 메뉴를 제공합니다.
- 아이콘을 더블클릭하면 웹 화면을 엽니다. 브라우저를 닫아도 앱은 계속 실행됩니다.
- 작업 재개는 이 실행 세션에서 중지했던 분석·동기화만 다시 켭니다. 로그아웃하거나 연결 설정을 바꾸면 재개 기록을 초기화합니다.
- 작업 중지는 진행 중인 분석도 중단할 수 있습니다. 복구 확인이 필요한 경우 웹 화면에서 안내에 따라 처리하세요.

## 설치 및 업데이트

- 기존 앱을 종료한 뒤 `0.3.1-setup.exe`를 기존 설치 위치에 실행하세요. 개인 연결 설정과 작업 자료는 보존합니다.
- 설치 후 바탕화면의 **메일 분석실**을 실행하세요. 트레이 아이콘은 **숨겨진 아이콘 표시(∧)** 안에 있을 수 있습니다.
- Mail/DB MCP와 AI 도구 연결은 웹 화면의 **설정 → 개인 연결 → 연결 환경**에서 설정합니다.

## 확인된 사항과 알려진 제한

- 정적 검사·빌드 및 관련 단위 테스트 23개가 통과했습니다. 네이티브 메뉴 명령, 중복 클릭 방지, 트레이 종료와 부모 연결 종료 시 정리를 검증했습니다.
- 별도 테스트 폴더에서 v0.3.0→v0.3.1 설치와 설정·작업 파일 보존, 바로가기 대상과 아이콘을 확인했습니다. 반복 실행 시 트레이가 중복 생성되지 않고 앱 종료 후 함께 정리됨을 확인했습니다.
- 자동 검증과 실제 사용자 클릭 검증은 구분합니다. 개인 계정 로그인·지정 메일 분석과 실제 Windows 메뉴 클릭 확인은 남아 있습니다.
- 설치 EXE에는 Windows Authenticode 서명이 없으므로 SmartScreen 경고가 표시될 수 있습니다.
