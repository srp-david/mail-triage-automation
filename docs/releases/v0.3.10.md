# v0.3.10 패치노트

기준 범위: 마지막 공개 버전 `v0.3.0-candidate.10`과 이번 `v0.3.10`의 배포 소스를 비교했습니다. 그 사이의 숫자 버전은 로컬 설치·검증용이었으며, 이번 배포에 변경 사항을 모두 포함합니다.

웹에서 개인 연결을 설정하고, 동기화·분석 요청 시 필요한 작업을 자동으로 실행할 수 있습니다. 바탕화면 바로가기와 트레이, 계정·보고서 화면을 개선하고 기술 문서를 설치 파일에 포함했습니다.

## 개인 연결과 MCP 자동 찾기

- 설정의 연결 환경에서 Mail MCP·DB MCP 주소, Codex·Claude 실행 경로와 ERP 코드·참고 자료 폴더를 저장할 수 있습니다.
- Codex·Claude에 등록된 HTTP MCP와 알려진 로컬 주소를 탐색하고, 연결 가능한 도구를 확인해 빈 입력란에 채웁니다. 여러 연결이 있으면 직접 선택하며, 저장해야 적용됩니다.
- AI 실행 파일 자동 찾기와 연결 확인을 추가했습니다. Codex 앱의 버전 폴더가 변경되어도 실제 실행 파일을 찾도록 개선했습니다.
- DB MCP는 데이터베이스·스키마·테이블 목록과 구조를 읽는 도구만 사용합니다.

## 앱 실행과 업데이트

- 바탕화면 바로가기와 Windows 트레이에서 화면 열기, 작업 일시 중지·재개, 앱 종료를 할 수 있습니다.
- 메일 동기화나 분석을 요청하면 필요한 백그라운드 작업이 자동으로 시작됩니다. 설정에서 실행기를 따로 켤 필요가 없습니다.
- 트레이에서 일시 중지한 상태나 복구가 필요한 작업은 안내에 따라 확인한 뒤 다시 요청합니다.
- 설정과 트레이에서 업데이트를 확인할 수 있습니다. 새 버전, 진행 상태와 오류를 표시하며 설치하거나 나중에 진행할 수 있습니다.

## 계정과 화면 사용성

- 설정을 연결·분석 준비 중심으로 정리하고 공유·장치 관리 항목을 제거했습니다.
- 관리자 계정 목록을 정리하고 비밀번호 변경을 내 계정 메뉴로 분리했습니다.
- 새로고침 중 저장된 로그인 상태를 확인할 때 로그인 화면이 잠깐 나타나던 문제를 수정했습니다. 통신 실패 시 다시 확인할 수 있습니다.
- 임시 비밀번호, 분석 이력과 공유 보고서 팝업의 줄 정렬·버튼 간격·작은 화면 배치를 개선했습니다.
- 일시 알림은 5초 뒤 닫히며 같은 알림이 다시 발생하면 표시 시간이 갱신됩니다.

## 공용 분석과 보고서 작업

- 같은 메일의 공통 식별과 팀 권한을 확인해 기존 분석을 조회하고 중복 분석을 방지합니다.
- 공유 보고서 조회, 보고서에 대한 질문과 답변, 명시적인 내용 반영·버전 관리 기능을 추가했습니다.
- 여러 사용자가 동시에 보고서를 수정할 때 이전 내용을 덮어쓰지 않도록 충돌을 안내합니다.

## 기술 문서 연결 오류 수정

- 기술 문서 버튼이 별도 개발 서버로 연결되어 `ERR_CONNECTION_REFUSED`가 발생하던 문제를 수정했습니다.
- 문서를 설치 파일에 포함하고 실행 중인 앱의 `/docs/`에서 제공합니다.
- 별도 문서 서버 없이 문서 탐색·한국어 검색·도표를 사용할 수 있습니다. 문서 버전은 설치본과 함께 갱신됩니다.

## 설치 및 업데이트

- Windows x64: 아래 Assets에서 `0.3.10-setup.exe`를 내려받아 실행하세요.
- 기존 설치는 진행 중인 작업을 마친 뒤 트레이에서 **앱 종료**를 선택하고 기존 위치에 설치하세요. 기본 위치는 `%LOCALAPPDATA%\MailTriagePilot`입니다.
- 기존 설정·로그인 저장소·작업 파일은 보존됩니다. 설치 후 바탕화면의 **메일 분석실** 바로가기로 실행하세요.
- 이전 candidate 릴리스는 보존합니다. 이번 릴리스부터 제목과 태그에 숫자 버전만 사용합니다.

## 확인된 사항과 알려진 제한

- 정적 검사, 관련 단위·UI 테스트, 합성 브라우저의 설정·세션 복원·알림·팝업·내장 문서 동작을 확인했습니다. 별도 설치 위치에서 0.3.9→0.3.10 업그레이드와 설정·작업 파일 보존을 확인했습니다.
- 개인 Mail MCP·AI 계정·ERP 읽기 자료를 연결한 실제 업무 분석과 다른 사용자 PC의 수용 검증은 별도로 필요합니다.
- 인증 헤더·OAuth·stdio 방식 MCP의 자동 가져오기는 지원하지 않습니다. AI 도구 설치와 제공자 로그인은 해당 도구에서 진행하세요.
- 앱의 업데이트 제공은 기존 테스트 채널 정책을 유지합니다. GitHub의 일반 릴리스 표기가 실사용 검증 완료나 stable 채널 승인을 뜻하지는 않습니다.
- 설치 EXE에는 Windows Authenticode 서명이 없어 SmartScreen 경고가 표시될 수 있습니다. 업데이트 메타데이터 서명은 설치 EXE의 코드 서명과 별개입니다.
