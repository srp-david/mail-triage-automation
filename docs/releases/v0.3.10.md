# v0.3.10 패치노트

<!-- 로컬 설치본. GitHub Release와 업데이트 catalog 미게시. -->
기준 범위: 로컬 v0.3.9 대비 변경입니다.

## 기술 문서 연결 오류 수정

- 기술 문서 버튼이 별도 개발 서버로 연결되어 `ERR_CONNECTION_REFUSED`가 발생하던 문제를 수정했습니다.
- 문서를 설치 파일에 포함하고 실행 중인 앱의 `/docs/`에서 제공합니다.
- 별도 문서 서버 없이 문서 탐색·한국어 검색·도표를 사용할 수 있습니다. 문서 버전은 설치본과 함께 갱신됩니다.

## 설치 및 확인

- 트레이에서 **앱 종료** 후 `0.3.10-setup.exe`를 기존 위치에 설치하고 실행하세요.
- 주 메뉴의 **기술 문서**를 누르면 앱과 같은 주소의 문서가 새 탭으로 열립니다.
- 기존 팝업 개선·동기화/분석 자동 실행·알림 자동 닫힘도 포함합니다.
- 브라우저에서 새 탭·한국어 검색·도표·하위 페이지 새로고침을 검증했고, 별도 폴더에서 0.3.9→0.3.10 실제 설치와 설정 보존·문서 제공을 확인했습니다.
