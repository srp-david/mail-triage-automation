# v0.3.6 패치노트

<!-- 로컬 설치본 초안. GitHub Release와 업데이트 catalog 미게시. -->
기준 범위: 로컬 v0.3.5 이후의 업데이트 사용성 개선입니다.

## 업데이트 확인

- 앱 시작·로그인 직후와 이후 1시간마다 확인합니다. 브라우저를 닫아도 앱이 실행 중이면 확인합니다.
- 설정의 **앱 업데이트**와 트레이의 **업데이트 확인** 메뉴를 추가했습니다.
- 현재 버전, 마지막 확인 시각, 최신 여부, 로그인 필요, 확인 실패를 구분해 표시합니다.
- 새 버전이 있으면 웹 안내와 트레이 메뉴에 표시하며 Windows 알림을 요청합니다.

## 설치 안내

- **지금 설치 / 나중에**를 선택할 수 있습니다. 나중에 선택한 버전은 설정에서 다시 설치할 수 있습니다.
- 다운로드 진행률, 검증 중, 작업 종료 대기, 설치·재시작 상태와 실패 안내를 제공합니다.
- 중복 설치를 막고 설치 전 배포 정보·서명·파일 해시를 재확인합니다. 로그인 상태가 바뀌면 아직 시작하지 않은 설치를 취소합니다.

## 설치 및 확인

- 트레이에서 앱을 종료한 뒤 `0.3.6-setup.exe`를 기존 위치에 설치하고 바로가기로 실행하세요.
- 관련 테스트 28개, 합성 브라우저·WinForms 메뉴 검증, 별도 홈의 v0.3.5→v0.3.6 설치·설정/작업 보존·제공 화면 대조를 통과했습니다.
- 실제 계정으로 게시된 새 버전을 다운로드·설치·재시작하는 전체 검증은 남아 있습니다. 이번 브라우저 설치 진행률 검증은 합성 상태를 사용했습니다.
- 현재 개인 설치본은 이번 작업에서 교체하지 않았습니다. Authenticode 및 공개 업데이트 metadata 서명·GitHub/catalog 게시 전입니다.
