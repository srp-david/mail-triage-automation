# v0.3.12 패치노트

기준 범위: `v0.3.11`과 이번 `v0.3.12`의 배포 소스를 비교했습니다.

비밀번호 변경이 실패했는데 로그인 화면으로 이동해 변경된 것으로 오해할 수 있던 문제를 수정했습니다.

## 비밀번호 변경 안내

- 현재 비밀번호가 틀리면 변경 화면을 유지하고 비밀번호가 변경되지 않았음을 알려줍니다. 입력란에 두 비밀번호를 다시 입력해 변경할 수 있습니다.
- 오류 안내를 화면 안에도 표시해 일시 알림이 사라진 뒤에도 확인할 수 있습니다.
- 최초 변경 시 현재 비밀번호 칸에 발급받은 임시 비밀번호를 입력하도록 안내합니다.
- 세션이 만료됐다면 다시 로그인하도록 안내합니다. 실제 변경 성공 시 새 비밀번호로 다시 로그인하는 흐름은 유지합니다.

## 설치 및 업데이트

- Windows x64: 아래 Assets의 `0.3.12-setup.exe`를 실행하세요.
- 기존 사용자는 진행 중인 작업을 마치고 트레이에서 **앱 종료** 후 기존 위치에 설치하세요. 기존 개인 설정과 저장소는 보존됩니다.
- 신규 사용자는 바탕화면의 **메일 분석실**을 열고 관리자가 발급한 계정과 임시 비밀번호로 로그인하세요. 공용 서버 주소는 자동 설정됩니다.

## 확인된 사항과 알려진 제한

- 단위·화면 테스트와 실제 브라우저·격리된 테스트 DB에서 비밀번호 오류 후 재시도, 변경 성공, 새 비밀번호 로그인, 로그아웃을 확인했습니다.
- 실제 사용자 계정의 비밀번호는 이번 검증에서 변경하지 않았습니다. 업데이트는 기존 테스트 채널 정책을 유지합니다.
- Windows Authenticode 서명은 없어 SmartScreen 경고가 표시될 수 있습니다. 업데이트 메타데이터 서명은 별개입니다.
