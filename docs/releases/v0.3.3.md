# v0.3.3 패치노트

<!-- 로컬 설치본 초안. GitHub Release와 업데이트 catalog 미게시. -->
기준 범위: 로컬 v0.3.2 이후의 계정 화면 개선입니다.

v0.3.3은 관리자 계정 정보를 보기 쉽게 정리하고, 개인 비밀번호 변경을 별도 메뉴로 옮긴 버전입니다.

## 관리자 계정 화면

- 계정 목록을 자동으로 불러오고 사용자명·표시 이름으로 검색할 수 있습니다.
- 이름, 사용자명, 권한, 사용 상태와 비밀번호 변경 필요 여부를 계정별 카드로 표시합니다.
- 계정 생성과 정보 수정은 필요할 때 펼쳐 입력하도록 정리했습니다.
- 임시 비밀번호는 대상 계정 이름과 함께 별도 창에서 확인합니다. 창을 닫으면 화면에서 지워집니다.

## 내 계정 메뉴

- 설정 하단의 비밀번호 변경을 주 메뉴 **내 계정**으로 분리했습니다.
- 새 비밀번호는 기존과 같이 12자 이상이며, 변경 후 다시 로그인합니다.
- 첫 로그인 시 필수 비밀번호 변경 흐름을 유지합니다.

## 설치 및 확인

- 기존 앱을 종료한 뒤 `0.3.3-setup.exe`를 기존 위치에 설치하세요. 이전 버전의 트레이·연결 환경 UI를 포함합니다.
- 관련 폼 테스트와 합성 브라우저에서 계정 목록·검색·수정·생성·초기화, 내 계정 이동·비밀번호 변경 후 로그아웃을 확인했습니다. 실제 계정은 변경하지 않았습니다.
- 별도 테스트 위치에서 v0.3.2→v0.3.3 설치 시 설정·작업 자료 보존과 새 UI 제공을 확인했습니다.
- Authenticode 서명이 없어 SmartScreen 경고가 표시될 수 있습니다.
