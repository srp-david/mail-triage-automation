# v0.3.13 패치노트

기준 범위: `v0.3.12`와 이번 `v0.3.13`의 배포 소스를 비교했습니다.

팀의 분석 이력을 함께 조회하고, 각 PC에서 Codex·Claude Code의 Windows/WSL 실행 환경을 선택할 수 있습니다. 분석 보고서의 기존 형식을 복원하고, 메일 상태 검색의 반복 조회와 업데이트 알림 표시를 개선했습니다.

## 팀 분석 이력과 계정 관리

- 같은 팀의 분석 이력과 보고서를 개인 연결 설정 없이 조회·검색할 수 있습니다. 분석 사용자와 관리자는 보고서를 편집하고, 조회 사용자는 읽을 수 있습니다.
- 원본 헤더로 동일 메일임이 확인되면 다른 팀원이 분석한 결과를 자신의 메일함에서도 확인합니다. 개인 처리 완료 표시는 사용자별로 유지합니다.
- 관리자는 팀을 추가하고 계정 소속을 지정할 수 있습니다. 자료가 있는 계정의 임의 팀 이동은 차단합니다.
- 원본 출처 권한이 없는 사용자에게 관련 메일의 제목·식별 정보가 노출되지 않도록 수정했습니다.

## WSL 실행 지원

- Codex와 Claude Code의 실행 환경을 각각 Windows 또는 WSL로 설정하고 배포판·Linux 사용자·실행 경로를 지정할 수 있습니다.
- 배포판 조회와 실행 확인을 제공합니다. WSL 내부 Python 3·AI 도구 설치와 로그인, WSL2 mirrored 네트워크가 필요합니다.
- WSL·방화벽 설정은 자동 변경하지 않습니다.

## 메일 검색과 업데이트 알림

- 서버에 메일 식별 확인 결과를 저장해 반복 검색과 앱 재시작 시 같은 헤더를 다시 읽지 않습니다. 새 메일만 추가 확인합니다.
- 헤더 부족과 통신 실패를 구분합니다. 동기화 이후 또는 **메일 목록 새로고침**에서 다시 확인할 수 있습니다.
- 새 버전 알림을 화면 하단에 표시해 좁은 창에서 내용과 버튼이 잘리는 문제를 수정했습니다.

## 분석 보고서 형식 복원

- 새 분석과 추가 답변을 반영한 재분석에서 메일 요약부터 회신 초안까지 기존 9개 항목을 사용합니다.
- 수정이 필요한 경우 대상 파일·수정 위치·변경 내용·검증 방법을 작성하도록 지침을 복원했습니다.
- 항목 누락·순서 오류·빈 본문이 있는 결과는 완료 보고서로 저장하지 않습니다. 이미 저장한 보고서는 그대로 유지하며 보고서 대화 답변에는 이 형식을 강제하지 않습니다.

## 설치 및 업데이트

- Windows x64용 `0.3.13-setup.exe`를 실행하세요.
- 기존 사용자는 진행 중인 작업을 마치고 트레이에서 **앱 종료** 후 기존 위치에 설치하세요.
- 공용 서비스에는 이번 버전에 필요한 팀 권한과 메일 식별 확인 기능이 적용되어 있습니다.

## 확인된 사항과 알려진 제한

- 단위·화면·격리 DB 테스트에서 팀 권한, 보고서 편집, 반복 검색, 원본 메일 권한을 확인했습니다. 실제 runtime DB 권한을 사용하는 로컬 Edge 검증도 통과했습니다.
- 합성 1,100건에서 반복 검색과 앱 재시작 후 추가 헤더 조회 0회, 신규 1건 추가 시 1회 조회를 확인했습니다.
- 실제 WSL 배포판에서 개인 AI 계정 로그인·분석·중지와 두 PC 업무 수용은 미검증입니다. 앱 밖에서 MCP의 기존 메일을 변경했다면 **메일 목록 새로고침**을 사용하세요.
- Windows Authenticode 코드 서명이 없어 SmartScreen 경고가 표시될 수 있습니다. 업데이트 메타데이터 서명은 별개입니다.
