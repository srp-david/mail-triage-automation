# v0.3.2 패치노트

<!-- 로컬 설치본 초안. GitHub Release·업데이트 catalog 미게시. -->
기준 범위: 로컬 v0.3.1 이후의 설정 화면 개선입니다.

v0.3.2는 연결 설정과 분석 준비를 쉽게 구분하고 입력 상태를 확인할 수 있도록 설정 화면을 정리한 버전입니다.

## 설정을 단계별로 구분

- **연결 환경**, **분석 준비**, **공유·장치 관리**, **중단 작업 복구** 탭으로 나눴습니다.
- 메일·DB 연결과 AI 도구를 카드로 묶었습니다. PC에서는 두 열로, 작은 화면에서는 한 열로 표시합니다.
- 실행 인수와 자동 찾기 상세 안내는 필요할 때 펼쳐 볼 수 있습니다.

## 입력과 저장 상태 안내

- 주소·실행 경로의 입력 여부와 실제 연결 검사 결과를 구분해 표시합니다.
- 저장하지 않은 변경을 표시하고 변경이 있을 때만 저장 버튼을 활성화합니다.
- 탭을 이동해도 입력 중인 값은 유지합니다. 저장 후에는 **다음: 분석 준비**로 이동할 수 있습니다.
- 읽기 자료가 없는 상태와 추가·삭제 동작을 더 쉽게 확인하도록 정리했습니다.

## 설치 및 확인

- 기존 앱을 종료한 뒤 `0.3.2-setup.exe`를 기존 위치에 설치하세요. 기존 트레이와 웹 연결 설정 기능을 포함합니다.
- 정적 검사, UI 테스트와 합성 브라우저에서 자동 찾기·수정·저장·새로고침·탭 이동 및 작은 화면 배치를 검증했습니다. 실계정 분석 결과를 검증한 것은 아닙니다.
- 별도 테스트 설치 위치에서 v0.3.1→v0.3.2 업그레이드 시 설정·작업 자료 보존과 새 UI 제공을 확인했습니다.
- Authenticode 서명이 없으므로 SmartScreen 경고가 표시될 수 있습니다.
