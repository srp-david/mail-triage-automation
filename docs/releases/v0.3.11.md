# v0.3.11 패치노트

기준 범위: `v0.3.10`과 이번 `v0.3.11`의 배포 소스를 비교했습니다.

처음 설치할 때 공용 API와 인증 issuer 주소를 입력하던 단계를 없앴습니다. 설치 후 앱을 열고 계정과 비밀번호로 로그인하면 됩니다.

## 공용 서버 자동 설정

- 신규 설치는 공용 API·인증 issuer·audience를 자동으로 설정합니다. 주소를 별도로 전달받을 필요가 없습니다.
- 기존 설정 파일이 있으면 그대로 사용합니다. 서버 주소·포트·개인 MCP·AI·읽기 자료 설정을 덮어쓰지 않습니다.
- 설치본에는 공개 서비스 주소만 포함합니다. 사용자 계정·비밀번호·토큰은 포함하지 않습니다.

## 설치 및 업데이트

- Windows x64: 아래 Assets의 `0.3.11-setup.exe`를 실행하세요.
- 신규 사용자는 설치 후 바탕화면의 **메일 분석실**을 열고 관리자가 발급한 계정과 임시 비밀번호로 로그인하세요. 첫 비밀번호 변경 후 웹 설정에서 개인 연결을 진행합니다.
- 기존 사용자는 진행 중인 작업을 마치고 트레이에서 **앱 종료** 후 기존 위치에 설치하세요. 기존 개인 설정과 저장소는 보존됩니다.

## 확인된 사항과 알려진 제한

- 공용 주소 자동 설정은 개인 Mail MCP·AI 도구의 설치나 로그인을 대신하지 않습니다. 개인 연결을 사용하는 실제 업무 분석은 별도 확인이 필요합니다.
- 업데이트는 기존 테스트 채널 정책을 유지합니다.
- Windows Authenticode 서명은 없어 SmartScreen 경고가 표시될 수 있습니다. 업데이트 메타데이터 서명은 별개입니다.
