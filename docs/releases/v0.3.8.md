# v0.3.8 패치노트

<!-- 로컬 설치본. GitHub Release와 업데이트 catalog 미게시. -->
기준 범위: 로컬 v0.3.7 대비 변경입니다. 이전 설정 정리·로그인 화면 수정도 포함합니다.

## 메일 동기화와 분석 자동 실행

- 메일함에서 동기화·분석을 요청하면 필요한 백그라운드 작업이 자동으로 시작됩니다.
- 설정의 수동 실행·중지 버튼을 제거했습니다. 연결 선택을 저장한 뒤 메일함에서 바로 요청하세요.
- 실행 중에는 중복 실행하지 않고 대기 중에는 새 요청을 바로 확인합니다.
- 트레이에서 일시 중지한 경우에는 재개를, 중단 기록이 남아 있으면 작업 복구를 안내합니다.

## 알림 자동 닫힘

- 일반 화면과 보고서 대화상자의 일시 알림은 5초 뒤 사라집니다.
- 같은 알림이 다시 발생하면 표시 시간을 새로 계산합니다.

## 설치 및 확인

- 트레이에서 **앱 종료** 후 `0.3.8-setup.exe`를 기존 위치에 설치하고 바로가기로 실행하세요.
- 연결 설정을 저장하고 메일함에서 동기화·분석을 요청하면 됩니다. 설정의 실행 상태 확인은 필수가 아닙니다.
- 합성 자료로 자동 실행·중복 방지·복구/일시 중지/업데이트 보호 및 알림을 검증했습니다. 개인 Mail MCP·Agent로 실메일을 처리하는 수용 시험은 별도입니다.
- 관련 테스트 28개·전체 빌드·실제 Chrome 검증을 통과했습니다. 별도 폴더에서 실제 설치 파일로 0.3.7→0.3.8 업그레이드 후 설정·작업 파일 보존과 새 UI 제공을 확인했습니다.
