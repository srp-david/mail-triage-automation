# v0.3.7 패치노트

<!-- 로컬 설치본 초안. GitHub Release와 업데이트 catalog 미게시. -->
기준 범위: 로컬 v0.3.6 설치 피드백 반영입니다.

## 설정 화면 정리

- 공유·장치 관리 탭과 팀 사용자·문서 모음 목록 조회를 제거했습니다.
- 기존 문서 모음 연결과 분석 준비의 출처·AI·실행 장치 설정은 보존합니다.

## 새로고침 시 로그인 화면 깜빡임 수정

- 저장된 세션을 확인하기 전에 로그인 화면이 나타나던 문제를 수정했습니다.
- 확인 중에는 로딩 화면을 표시하고, 세션 확인이 끝나면 기존 페이지로 이동합니다.
- 통신 실패는 재시도 화면으로 안내합니다. 세션이 없는 경우에만 로그인 화면을 표시하고 첫 비밀번호 변경 흐름을 유지합니다.

## 설치 및 확인

- 트레이에서 앱을 종료한 뒤 `0.3.7-setup.exe`를 기존 위치에 설치하고 실행하세요.
- 관련 UI 테스트 19개와 응답 지연을 넣은 합성 브라우저에서 3회 새로고침, 오류 후 재시도, 로그아웃 상태, 불필요한 목록 조회 제거를 확인했습니다.
- 별도 홈에서 실제 설치 파일로 v0.3.6→v0.3.7 업그레이드하고 설정·작업 파일 보존과 새 화면 제공을 확인했습니다.
- 개인 설치본 교체·실계정 로그인·GitHub/catalog 게시·서명은 별도입니다.
