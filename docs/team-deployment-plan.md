# 팀 인증·배포 계획 통합 안내

2026-09-17부터 인증·설치·팀 배포 계획은 [통합 구현 계획](implementation-plan.md)에서 관리한다. 별도 계획서에서 작업 순서와 기술 선택을 중복 유지하지 않는다.

현재 기준은 **회사 이메일 인증 후 자동 가입 → 공용 이력 API·PostgreSQL → 팀원 PC의 웹 앱·개인 AI agent·MCP → 선택적 공용 실행**이다. 기존 초대 전용·개발자 PC 공용 파일럿·전체 Worker 중앙 이전을 기본 경로로 삼던 안은 대체되었다.

통합 계획서의 관련 내용:

- 4절: 기술 스택과 패키지 구조
- 5~7절: Auth0 인증·권한, PostgreSQL 모델, API·작업 수명
- 8~9절: Codex/Claude 연결과 Windows 설치·업데이트
- 10~11절: 공용 서버·백업·기존 이력 이관·롤백
- 12~14절: 개발 단계·완료 기준·미확정 결정·향후 공용 실행

이전 제안의 비교 근거와 당시 조건은 [이전 배포 제안 원문](team-deployment-proposal-2026-09-17.md)에 보존했다. 문서 전체 안내는 [문서 목록](README.md)을 따른다. 이번 통합은 설계 정리이며 실제 로그인 구현·서비스 구매·외부 배포는 수행하지 않았다.
