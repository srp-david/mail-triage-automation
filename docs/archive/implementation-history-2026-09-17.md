## 목표와 범위
별도 프로젝트의 Docker 웹 앱과 erp-manager 직접 스킬 실행이 하나의 이력 API와 DB를 사용한다.
웹에서는 Claude 2차 리뷰를 실행하지 않는다. Orca 직접 실행의 리뷰는 유지하되 결과 저장은 공용 API로 통일한다.
메일 발송, 읽음 처리, ERP 코드 변경, ERP DB 변경은 포함하지 않는다.
기본 접속 범위는 개인 PC localhost이다.
2026-09-17 사용자 요청으로 **사용자별 로그인과 팀 내부 운영·배포 준비**를 후속 범위에 추가한다. 현재 localhost 운영은 유지하며, 이 요청에서는 설계와 작업 계획을 추가한다. 권장안과 플랫폼 비교는 [팀 인증·배포 계획](team-deployment-plan.md)을 따른다.

## 구조
- 웹/API: TypeScript, 메일 목록/상세/첨부, 동기화 버튼, 분석 요청, 이력/보고서.
- Worker: Codex 비대화형 실행, 공통 스킬/업무 문서 참조, mail MCP와 DB MCP 조회.
- PostgreSQL: 메일 식별, 실행 상태, 불변 보고서 버전, 리뷰, 동기화 기록, 질문/답변, 지식 반영 제안.
- ERP 코드는 읽기 전용 마운트. 공용 DB는 Docker 영구 볼륨. 인증 정보는 Git/이미지에 포함하지 않는다.
- erp-manager: 업무 규칙의 원본. API 클라이언트와 실행 환경 안내를 추가한다.
- 직접 실행도 공용 API가 필요하다. API/DB만 실행하고 웹 Worker는 끌 수 있다.
